  3. 3D Chess with Robotic Arms

    3D chess game built with React Three Fiber, featuring two procedural 6-DOF robotic arms that physically move pieces on the board. The arms use a custom closed-form 2-link IK solver, with phase-based animation, choreographed captures, and full chess rules powered by chess.js. All visuals — board, pieces, and robotic arms — are generated at runtime from Three.js primitives, with no external 3D assets.

  4. AI Chat Assistant

    An AI chat assistant powered by OpenAI and integrated with CRM REST API for customer identification and order lookups. The backend parses the YML catalog to generate real-time product recommendations, supports SSE streaming, and runs on FastAPI + Railway with Docker. The result is a responsive website widget that helps customers choose products and check orders without adding support headcount.

  5. staya ai studio

    staya ai studio is a Vite + React + TypeScript image editing app designed for branded photo workflows, including dog replacement, human replacement, and environment generation. It supports masking, reference images, before/after comparisons, local gallery storage via IndexedDB, and AI-powered image generation and editing through backend routes connected to Gemini and the OpenAI Image API.
